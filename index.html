📲 Collega il tuo iPhone

Il tuo indirizzo personale per Comandi Rapidi. Ognuno usa il proprio, dal proprio iPhone. Non condividerlo.

—
  1. Comandi Rapidi → Automazione → + → Transazione. Scegli le carte, poi Esegui immediatamente → Avanti → Nuovo comando vuoto.
  2. Aggiungi l'azione Ottieni contenuti dell'URL e incolla l'indirizzo copiato (finisce con &i=).
  3. Con il cursore alla fine, tocca la variabile Input comando sopra la tastiera, poi toccala di nuovo e scegli Importo.
  4. Scrivi &e= e inserisci di nuovo Input comando, scegliendo Esercente.
  5. Fine. Non serve cambiare metodo, intestazioni o altro.
